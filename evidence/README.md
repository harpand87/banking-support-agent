# Evidence

`evaluation_offline.json` is generated by `python -m app.evaluate`. It contains aggregate metrics, fixed case IDs, decisions, and source IDs; it omits input and response text. Re-run it after changing the corpus, safety logic, tools, or evaluation cases.

Store only sanitized screenshots, JSON outputs, comparison tables, evaluation results, and logs here. Do not store raw user text containing PII, credentials, account identifiers, or provider secrets. For live comparisons, record model, date, prompt variant, and cost without persisting secrets or customer content.
